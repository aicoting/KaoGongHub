## 内容规划

仓库会围绕以下方向持续更新：

- 📢 **招录信息**：整理公务员、选调生、事业编、国企央企的招录公告与关键时间节点。
- 🔍 **岗位分析**：拆解专业、学历、政治面貌、基层经历等报考条件，分享岗位筛选方法。
- 📖 **备考干货**：行测、申论、面试、公共基础知识的学习方法、解题思路与备考规划。
- 🎯 **上岸经验**：从报名、笔试、资格审查到面试、体检、考察的真实经历与复盘。
- 🏢 **国企央企求职**：国网、南网、运营商及各类央企国企的招聘特点、简历与面试经验。

## 关于这个仓库

这里不贩卖焦虑，也不承诺所谓的捷径。所有内容均基于个人经历与公开信息整理，招录政策、考试时间与岗位条件请以官方公告为准。

愿这里的每一篇整理，都能让你真正学到一点东西。
